OZOR LOGO PACKAGE

OZOR-original-transparent.png: unchanged approved original (1983 x 793), transparent RGBA.
OZOR-transparent.webp: lossless web copy with transparency.
OZOR-transparent.tiff: lossless TIFF with alpha.
OZOR-white.jpg: white background, since JPG does not support transparency.
OZOR-vector.svg: actual vector paths traced from the approved image; no embedded raster and no font dependencies. Transparent background.
OZOR-vector.pdf / .eps: scalable exports from the SVG.

Vector tracing preserves the original silhouette closely, but small edge and color differences are possible. Raster texture is replaced with solid colors in the vector files. Use the original PNG when exact image fidelity is required.
